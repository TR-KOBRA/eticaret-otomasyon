# Kaynaklar

Otomasyonun "bilgi bankası". Dokümanlar burada toplanır, Claude okuyup özetler,
modüller bu özetlere göre kurulur/güncellenir.

- `gelen/` → Ham dokümanları buraya at (PDF, .md, .txt, ekran görüntüsü, link listesi `linkler.txt`).
- `ozetler/` → Claude'un her dokümandan çıkardığı uygulanabilir kurallar (kaynak, tarih, hangi modülü etkilediği).

Dokümanlara API anahtarı, şifre ya da kişisel veri koyma.
